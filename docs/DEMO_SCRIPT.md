## 第一部分：单会话主线（一镜到底，约 5 分钟）

**原则：不新建会话。** 所有能力在一个对话框里自然长出来，顺便展示多轮记忆。

### 轮次 ① —— 冷启动问答（过程直播 + 表格结论）

输入：`上个月 GMV 多少？`

- 看点：过程卡实时直播（检索指标 → 护栏校验 → 执行），然后表格结论
- 话术：**"看左边过程卡——AI 每一步在干什么全程可见。它先检索了指标口径，确认 GMV 必须带 completed 状态，过 AST 护栏才执行。没有一步是黑盒。"**

### 轮次 ② —— 复合分析 + 计划审批（全片高潮）

输入：`帮我分析近3个月各渠道GMV的表现，并生成一份分析报告`

- 看点：**计划审批卡弹出** → 逐步批准 → SQL 子 Agent 查数落句柄 → 报告 Agent 组装 → 报告卡
- 话术：**"复杂任务 AI 不擅自动手——先提交执行计划，人批准了才开工。这就是『LLM 决定做什么，工作流保证不能做什么』。"**
- 注意：计划卡批准后约 30~60 秒出报告，等待段剪辑加速

### 轮次 ③ —— SQL 透明模式

操作：展开过程卡 → 点 `▸ SQL` → 展示原文 → 复制 → 手改重跑（改个条件）

- 话术：**"数字怎么算的完全可审计。你甚至可以手改它的 SQL 重跑——当然，还是要过同一套护栏。"**

### 轮次 ④ —— 数据质量体检（对话内触发）

输入：`帮我做一次 orders 表的数据质量体检`

- 看点：profile_table 过程卡（行数/空值率/异常行/质量提示）
- 话术：**"分析之前先验货：缺失率、异常值先亮出来，结论可信度透明。"**

### 轮次 ⑤ —— 个性化记忆

输入：`记住，我们说的销售额都指净销售额`

- 看点：AI 回"已记住"
- 话术：**"口径反问只问一次，越用越懂你。"**

### 轮次 ⑥ —— 安全护栏（面试官最在乎）

输入：`导出所有用户手机号`

- 看点：AI 拒绝 + 解释 PII 拦截
- 话术：**"PII 字段 AST 级拦截；只读连接；全系统唯一写入口。AI 拿不到任何写通道。"**

### 轮次 ⑦ —— 记忆生效（点睛之笔）

输入：`那净销售额呢？最近 3 个月`

- 看点：**它没有再反问口径，直接按净销售额算**——轮次 ⑤ 记忆当场生效
- 话术：**"看到没——记住了之后体验就顺了。"**

### 轮次 ⑧ —— 图表能力（可选）

输入：`近 6 个月每月订单量趋势`

- 看点：折线图生成，悬停看数值

## 第二部分：页面巡礼（各 20~30 秒，切完即回）

> 从对话页出发依次切换，每页一句"这页是什么 + 一个亮点"。

### 1. 看板页

- 切"内置演示数据" + 近 6 个月 → KPI + 趋势图
- 切"数据体检" → 空值率/异常行/质量提示
- 话术：**"经营看板看业绩，数据体检看可信度——同一个数据源两个视角。还支持自定义起止日期。"**

### 2. 报告中心

- 产物总览、搜索、按会话跳转、删除
- 话术：**"每份报告跨会话可查，重启不丢，还能一键删除。"**

### 3. 设置 → 个性化

- 总开关（含成本诚实提示）+ 三类记忆 + 导入导出
- 话术：**"记忆全透明可控：能看、能改、能删、能关。关了就忘，开了就懂你。"**

### 4. 设置 → 工具

- 10 个 SQL 工具清单 + 调用计数
- 话术：**"工具可裁剪，但护栏工具锁死——『关掉护栏』不是可选项。"**

### 5. 设置 → LLM 配置

- 任意 OpenAI 兼容端点 + 连通性测试
- 话术：**"DeepSeek、通义、智谱都能接，Key 只存本机。"**

## 翻车预案

| 翻车 | 处理 |
|---|---|
| 计划审批卡没弹（模型直答） | 说"我们再明确一点"+ 复述一遍问题；仍不弹就切演示模式继续 |
| live 回答超时 | 等待段剪辑加速；或说"实时执行需要几秒"，剪掉 |
| 口径反问意外弹出 | 顺势演示 HITL（"看，它不懂就问"），选完继续 |
| 数据窗口过期 | 重跑 `python -m app.seed_data` |

## 面试深挖 Q&A 预案

| 可能追问 | 答法 |
|---|---|
| 为什么多 Agent 而不是一个？ | 工具隔离：主 Agent 上下文没有数据工具 schema，选错率与 token 双降；"子图即工具，单动作不包子图" |
| 怎么防幻觉？ | 语义层白名单 + AST 护栏 + 洞察纯代码计算 + 46 条确定性评测 |
| 和 DB-GPT/WrenAI 区别？ | 它们是平台；这是单机零配置 + 护栏深度 + 评测纪律的参考实现。语义层思想与 WrenAI 同源，护栏在 AST 层更狠 |
| token 成本怎么控？ | 上下文经济性（句柄协议/按需工具/记忆注入）+ DeepSeek 缓存计费 + 上下文压缩在路线图 |
| HITL 怎么实现？ | LangGraph interrupt/resume，三种 HITL 同一机制，服务端判定不靠 prompt |
