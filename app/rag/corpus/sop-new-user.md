# SOP：新用户与首单分析

适用场景：「新用户怎么样 / 注册转化 / 首单表现 / 拉新效果」类问题。
目标：分清「新增用户」和「首单新客」两个口径，给出转化漏斗。

## 口径区分（最容易错的地方）

- **新增用户数（new_users）**：按 `users.register_date` 统计的注册数，与订单无关。
- **首单新客**：在统计时间内下了**第一笔**完成订单的用户。需基于 orders 计算：
  用户维度的最小完成订单日期落在统计窗口内。两者数值差异很大，不能混用。
- 「付费用户数（active_users）」是窗口内有完成订单的去重用户，含老客。

## 分析步骤

1. 注册趋势：按月统计 new_users（users 表，register_date 按月分组）。
2. 注册→首单转化：
   - 用户首单月份 = MIN(CASE WHEN status='completed' THEN date_trunc('month', created_at) END)
     按 user_id 分组。
   - 转化率 = 窗口内注册且已产生首单的用户 / 窗口内注册用户。
   - 注册到首单的间隔分布：首单日期 - register_date，看中位数与 7 日内占比。
3. 新客质量：首单新客的客单价 vs 整体客单价；按会员等级（users.level）分层。
4. 新客留存口径提示：演示库没有事件表，做不了严格留存（次日/7 日活跃），
   只能用「后续月份是否再次下单」近似（复购），说明口径限制。

## 常用维度

- 地区：users.region_id JOIN regions；拉新强的地区 vs 转化强的地区可能不同。
- 渠道：首单订单的 channel_id，看哪个渠道承接新客多。

## 输出要求

- 结论先给转化漏斗数字：注册 → 首单 → 复购（近似）。
- 表格列：月份、新增注册、其中已首单、首单转化率。
