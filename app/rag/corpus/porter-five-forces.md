# 技能：波特五力分析

适用场景：「用波特五力分析 / 行业竞争格局 / 竞争压力评估」类问题。
目标：五力逐项分析，能用数据支撑的用数据，不能的明确标注定性判断。

## 五力与可用数据映射

1. 同业竞争（可用数据）：delegate_sql 取品类集中度（TOP2 品类 GMV 占比）、
   各渠道订单量格局——头部占比越高竞争越集中，如实解读。
2. 买方议价力（可用数据）：客单价水平与趋势、退款率（refund_rate，全状态口径）、
   大促月 GMV 占比——退款率高 / 对促销依赖重，说明买方强势。
3. 供应商议价力（定性）：演示库无供应商与成本数据，只能定性讨论并声明
   「缺乏内部数据支撑」。
4. 新进入者威胁（定性）：行业门槛的定性判断，禁止引用编造的行业数字。
5. 替代品威胁（定性）：定性讨论；可用品类间此消彼长的 GMV 趋势做间接佐证。

## 执行步骤

1. 先声明：本次分析哪些力有数据支撑、哪些是定性判断。
2. 有数据的两力先 delegate_sql 取数，数字带口径（时间范围、status 过滤）。
3. 五力逐项给「强 / 中 / 弱」评级 + 一句依据。
4. 总评：综合五力给出竞争压力结论 + 2~3 条应对建议，建议与最强压力一一对应。

## 常见陷阱

- 把五力做成五个「名词解释」而不落到本业务：每个力必须落到自己的数据或业务事实。
- 用编造的行业数据填充供应商/新进入者两力——禁止，如实说明缺数据。
- 买方议价力引用退款率时必须用全状态口径（分母含未完成订单），别加 completed 过滤。

## 输出要求

- 五力表格：力量、评级（强/中/弱）、依据（数据引用或「定性判断」）。
- 总评与建议放最后，建议与评级最强的压力一一对应。
- 引用的业务数字标注口径。
