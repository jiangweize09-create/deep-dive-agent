# 技能：SWOT 分析

适用场景：「用 SWOT 分析 / 优势劣势分析 / 竞争态势怎么样」类问题。
目标：把定性框架与真实数据结合，产出四象限结论与行动建议，不空谈。

## 执行步骤

1. 明确对象：先确认分析对象是整体业务还是某个品类/渠道（用户没说就按整体做并声明假设）。
2. 数据底座（可选但推荐）：delegate_sql 取近 6~12 个月 GMV、订单量、客单价趋势，
   以及品类/渠道结构——这些是 S/W 象限的「事实证据」。
3. 填充四象限：
   - S（内部优势）：增长快、客单价高、强势渠道/品类等，每条尽量挂一个真实数字。
   - W（内部劣势）：下滑维度、低效渠道、结构短板等，同样要有数字或口径支撑。
   - O（外部机会）与 T（外部威胁）：行业与环境的定性判断，明确标注「定性判断，非数据结论」。
4. 结论：每个象限 2~4 条；给 3 条行动建议，每条对应至少一个象限的证据。

## 常见陷阱

- 全程无数据支撑的「印象派」分析：能查到的维度必须查，数字来自真实查询。
- 因素放错象限：S/W 是「我们自己」，O/T 是「外部环境」，别混。
- 演示库只有内部经营数据，O/T 缺乏外部数据源时如实说明，禁止编造行业数字。

## 输出要求

- 四象限 Markdown 表格（S/W 一行、O/T 一行）。
- 行动建议 3 条，每条标注依据象限。
- 引用的业务数字标注口径（时间范围、status 过滤）。
